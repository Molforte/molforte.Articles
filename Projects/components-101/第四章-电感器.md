# 01-何为电感器
## 概念

**通电前**：导线中无电流，周围不存在磁场，线圈中无磁通量。

**通电后**：导线中电流从无到有（变大），导线周围也会从无到有（变大），导致线圈的磁通量变大，且电感器会阻碍电流变大，这种阻碍不能禁止电流变大，知识延缓了电流变大的速度，即：电流最终还是会变大，知识变大的速度，与没有电感相比较慢。

**能量转换**：电感阻碍电流变大时，有一部分电能转换成了磁能，这部分磁能被储存在了电感器中，当电流达到稳定状态后，磁能转化为电能的过程也就结束了。

## 总结

电感器时通过电能与磁能之间的相互转化，实现了平滑电流，对电流有一种“来拒去留”的反应。
+ 电流突然出现，或突然变大，电感器会抑制一下，**让它平缓地出现火变大**。
+ 电流突然消失，或突然变小，电感器会抑制一下，**让它平缓地消失或变小。

电感器是“磁能的暂存器”。

## 电感的决定式

$$
L=μ\frac{N^{2}A}{l}
$$

+ $L$：电感值（衡量电感器存储磁能的能力，也理解为：**抑制电流变化的能力**）
+ $μ$：磁导率（线圈芯部材料的磁导率）。
+ $N$：线圈的匝数。
+ $A$：线圈的截面积。
+ $l$：线圈的长度。

# 02-电感的单位、参数

## 单位
+ 标准单位：亨利（简称亨）符号是H，单位**电流变化率**下，电感器产生的反向的电压能力。
+ 1H的含义：电流变化速率为1A/时，如果该电感器能产生1V的反向电压，则电感值是1H。

定义式：
$$
\epsilon=-L\frac{dI}{dt}
$$

+ $\epsilon$：为电感器两端产生的感应电动势（单位：伏特，V）
+ L：为电感值（单位：亨利，H）
+ $\frac{dI}{dt}$为电流变化的速率（单位：安培每秒，A/s）

## 参数

+ 电感值：衡量电感器存储磁能的能力，也可理解为：抑制电流变化的能力。
+ 直流电阻：直流电阻（DCR）是指电感器金属导体中固有的电阻可以将其理解为与电感器串联的电阻器，通常要求直流电阻的阻值尽可能地小。
+ 精度：实际电感值与标称值之间的误差范围，精度越高，实际值越接近标称值。
+ 饱和电流：电感器达到饱和状态的临界电流值。

# 03-电路继电器

## 概念

**概述**：电磁继电器是利用电磁感应原理制成的一种电磁开关，它能通过：低电压、低电流的电路，来控制高电压、高电流的电路。

普通继电器：适合对功耗要求不严格、不涉及长期保持出点状态的场景。
![普通继电器图示]({{IMG:普通继电器图示.png}})

磁保持继电器：适用于对功耗要求严格、涉及到长期保持触点状态。
![磁保持继电器图示（小米宣传图）]({{IMG:磁保持继电器图示（小米宣传图）.png}})

## 关键参数：

+ **线圈电压**：电磁继电器线圈工作所需的电压，常见的有5V、12V、24V。
+ **最大切换电压**：继电器能够安全切换到最大电压，继电器的触电必须能承受此电压，超出此电压可能导致触电烧蚀，导致接触不良或形成电弧。
+ **最大切换电流**：继电器能够安全切换的最大电流。
+ **动作时间**：给线圈施加电压后，线圈开始工作，到触电完成接触所需要的时间。
+ **触点形式**：常开触点、常闭触点、转换触点。

# 04-蜂鸣器

## 概念

**概述**：蜂鸣器是一种能发出声音的电子元器件，常用于：报警音、提示音、音频信号输出等场景。

![蜂鸣器示意图]({{IMG:蜂鸣器示意图.png}})

## 有源蜂鸣器VS无源蜂鸣器

### 有源蜂鸣器（自激式蜂鸣器）

1. 内部自带音频震荡源。
2. 内部震荡源频率固定，所以音调固定。
3. 常用于单一提示音场景（火灾报警）。
4. 外观通常会大一些。
5. 出厂时顶部有贴纸密封。

### 无源蜂鸣器（它激式蜂鸣器）

1. 内部无音频震荡源，需要外部提供。
2. 可灵活控制声音的大小和音调。
3. 常用于多级提示音场景（游戏机音效）。
4. 外观通常会小一些。
5. 出厂时顶部无贴纸密封。

## 关键参数

+ 工作电压：蜂鸣器能正常发声的电压，过高的电压可能导致蜂鸣器损坏。
+ 外观大小：要结合电路板的尺寸，选择合适大小的蜂鸣器。
+ 驱动方式：区分好是有源蜂鸣器还是无源蜂鸣器。
+ 声压：声压表示声音的强度，声压越高，声音越大。

## 原子结构

![原子结构]({{IMG:原子结构.png}})

## 关于电子

+ 每个电子带一个单位负电荷
+ 每个质子带一个单位正电荷
+ 中子不带电
+ **每层最多容纳的电子数是$2n^{2}$**
+ 最外层电子数为8时，是较稳定的状态
+ **同种电荷互斥，异种电荷相吸**

# 02-电流

电流方向和电子方向相反。

十九世纪初：“电流方向”是指正电荷的移动方向。

后来：对于金属导体，正电荷没移动，其实是电子在移动。

## 概念
+ 概念：电荷的**定向移动，形成了电流**，衡量电流的大小，要看单位时间内通过导体横截面的电荷量。
+ **补充：对于金属导体来说，是负电荷（电子）定向移动。**
+ 单位：安培（A），简称：安。
+ 1A的含义：在1秒钟内有$6.22×10^{18}$个单位电荷通过了导体的横截面。
+ **备注**：$6.22×10^{18}$个单位电荷的总电量为1库伦(C)

**不必纠结1A的含义是什么，因为以后几乎不说。**

# 03-电场电势电势能

## 迁移部分

### 重力势能
1. 物体在重力场中所具备的能量。
2. 与所处位置、物体质量均有关。

### 重力势
1. 重力场中某个位置给物体“赋予重力势能”的本领。
2. **与质量无关**，与位置有关，是重力场的特性。

## 电场电势电势能

### 电势能
1. 描述带电粒子在电场中所具备的能量。
2. 与所处的位置，带电量均有关。

### 电势
1. 描述电场中某位置给带电粒子“赋予电势能”的本领。
2. **与试探粒子带电量无关**，与位置有关，是电场的特性。

# 04-电压（电势差）

## 概念
+ 概念：**两点之间电势的差值（电势差），衡量电压的大小，要看电势差的大小**。
+ 单位：伏特(V)
+ 1V的含义：电场对1库伦(C)电荷，做了1焦耳(J)的功。

---
# 05-电阻

## 概念
+ 概念：**材料或元器件对电流的阻碍。**
+ 单位：欧姆(Ω)，简称欧。
+ 1Ω的含义：给导体施加1V的电压，此时导体的电流如果为1A，那这个导体的电流就是1Ω。

# 07-欧姆定律

## 三个公式
$$
I=\frac{U}{R},R=\frac{U}{I},U=IR
$$

## 决定式与定义式
### 决定式
用于描述一个物理量由什么决定。仅通过其固有属性进行定量分析。
$$
R=ρ\frac{L}{A}
$$
### 定义式
用于描述一个物理量是什么，以及如何通过其他物理量测量或计算出来。
$$
R=\frac{U}{I}
$$

# 08-直流电和交流电

## 直流电
+ 有固定的正负极，且电流方向始终不变的电流
+ 全称：Direct Current，简称DC。
+ 举例：干电池、锂电池、光伏发电板等。

### 交流电
+ 无固定正负极，且电流方向随时间周期性变化。
+ 全称：Alternating Current，简称AC。
+ 举例：家庭用电。

周期：交流电完成一个完整的波动循环所需的时间。

### 结论性内容

+ 家庭用电是正弦交流电。
+ 交流电没有正负极之分，有零线和火线之分。
+ **零线和火线：零线电势始终为0，火线电势不断变化，有时高于0，有时低于0，这样就形成了交变电流。**
+ 家庭用电的220V指交流电的有效电压。
+ **峰值电压**：交流电在一个周期中达到的最大电压值，**220V的交流电的峰值电压为：$200\sqrt{2}$ 约为311V**。
+ **有效电压**：让交流电和直流电，分别通过同一个电阻，在交流电的一个周期内，若二者产生的热量相等，那么这个直流电的电压，就是交流电的有效电压。
+ **50Hz的含义**：50Hz是频率，表示1s内完成了50个周期，每个周期包含俩次方向的变化，所以1s内电流的方向变化了100次。

交流→直流：整流（Rectification）
直流→交流：逆变（Inversion）

# 09-强电和弱电

## 强电
电压通常较高，对人体伤害较大，必须采取防护措施，主要用于能源传输和高功率供电。

## 弱电
电压通常较低，一般不超过36V，基本不会造成人身危险，主要用于传输信号或低功率供电。

## 电流的危险性

+ 通过人体的电流大小，直接决定了电击的危险性
+ **感知电流**：能引起人感觉的最小电流，**约0.7mA ~ 1.1mA左右**，有很轻微的刺痛感，但不会造成伤害。
+ **摆脱电流**：能自主摆脱的最大电流，**约10mA ~ 16mA左右**，有明显的肌肉收缩，不要持续接触。
+ **致命电流**：能在短时间危及生命的最小电流，**约为50mA**，有明显的呼吸困难，产生心脏室颤。

# 12-电功率

## 电功率
+ 电功率：指电流在单位时间内做的功（表示用电器消耗电能快慢的一个物理量）
+ 单位：瓦特(W)，简称瓦。
+ 公式：$P=UI$

## 千瓦时

+ **瓦时**：$瓦时 = 功率(W)×时间(h)$，功率为1W的用电器工作1h，它消耗的电能就是1瓦时(1Wh)。
+ **千瓦时**：瓦时的千倍，功率为1kW的用电器工作1h，它消耗的电能是1千瓦时（1kWh，俗称1度电）。

+ **安时**：**1安时表示该电池以1A的电流持续工作1h**，通常用于描述大容量电池。
+ **毫安时**：安时的千分之一，通常用于描述小容量电池。

# 13-焦耳定律

### 焦耳定律
+ 内容：电流通过导体产生的热量，与电流的平方成正比，与电阻成正比，与通电时间成正比。
+ 单位：焦耳(J)，简称焦。
+ 公式：$Q=I^{2}Rt$
+ 单位换算：进位为1000，例如$1kJ=1000J$

# 14-元器件的封装方式

## 插件封装

元件有引脚，必须穿过电路板上的孔焊接。
![插件封装]({{IMG:插件封装.png}})

+ 优点：机械强度高，散热能力好。
+ 缺点：体积较大、组装效率较低。
+ 适用于：工业控制设备、大功率设备。

## 贴片封装

元件直接焊接在电路板表面，无需打孔。
![贴片封装]({{IMG:贴片封装.png}})

+ 优点：体积小、重量轻、更适合自动化生产。
+ 缺点：机械强度骄较弱，散热能力略差、维修难度略高。
+ 适用于：消费电子、通信设备、高密度电路设计。

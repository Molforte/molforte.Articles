# 01-什么是电容器

存储电荷的容器

## 充电、放电电容器与电池的区别

### 电容器

1. 储能过程是物理变化。
2. 充电、放电速度很快。
3. 存储的电量相对较少。
4. 自放电率较高。

### 电池

1. 储能过程是化学变化。
2. 充电、放电速度较慢。
3. 储存的电量相对较多。
4. 自放电率较低。

# 02-电容器的单位、参数

## 单位

+ 标准单位：法拉（简称法）符号是F，用来表达单位电压下，电容器存储电荷的能力。
+ 1F的含义：在电容器两端加1V的电压，如果该电容器能存储1库伦的电荷，那该电容器的容值为1F。
+ 定义式：
$$
C=\frac{Q}{U}
$$
C 为容值，单位为法拉（F）
Q 为电荷量（C）
U 为电压（V）

## 电容

+ **容值**：表示电容器在单位电压下，存储电荷的能力。
+ **额定电压**：电容器在正常工作状态下，能承受的最大电压。
+ **精度**：实际容值与标称容值之间的误差范围，精度越高，实际值就越接近标值。
+ **极性**：有些电容器是有极性的，必须将正负极正确地接入电路。

# 04-容抗

## 概念

电容器虽然能“通交”，但交流电通过电容器时，也会有一定损失。

![电容容抗示例]({{IMG:电容容抗示例.png}})

决定式：
$$
X_{c}=\frac{1}{2\pi fc}
$$

+ $X_{c}$：容抗，单位为欧姆。
+ $f$：交流信号频率，单位为赫兹。
+ $c$：容值，单位为法拉。
+ $\pi$：圆周率。

电容容值($C$)固定，信号和频率($f$)越大，容抗越小。
信号频率($f$)固定，电容的容值($C$)越大，容抗越小。

**电阻和电容，都能对电流产生阻碍作用，二者的区别是：电阻会发热，电容不发热**。

## 阻抗、容抗、感抗

阻抗分为：是电路中总的“阻力”，描述的是电路中多种因素对电流的总阻碍作用。**电阻，容抗，感抗**。

+ 电阻：表示材料火电阻器对电流的固定障碍，主要是能量的耗散（发热）。
+ 容抗：由电容产生的对电流的“动态阻碍”，随交流电的频率增加而减小。
+ 感抗：由电感产生的对电流的“动态阻碍”，随交流电的频率增加而增加。

# 05-陶瓷电容

以陶瓷为电介质的电容器，通常无极性的，是电子设备中使用量最多的一种电容器。

![介电常数表]({{IMG:介电常数表.png}})

陶瓷：任何金属的氧化物（$Al_{2}O_{3}、BaTiO_{3}……$)都可以叫陶瓷，所以它的种类繁多，成分差异很大，所以介电常数的范围非常广。

![两种陶瓷电容构造]({{IMG:两种陶瓷电容构造.png}})

1. MLCC是世界上用量最大、发展最快的电子元器件之一。
2. MLCC又被称为“电子工业大米”。
3. 多层精密结构，工艺比较复杂。

**优势**：成本低、稳定性高、耐高温、耐高压、损耗较小。
**适用于**：高频电路、噪声去除、过滤杂波等场景。

![瓷片电容和MLCC二者比较]({{IMG:瓷片电容和MLCC二者比较.png}})

# 06-电解电容

电解电容：其内部充有电解质（电解质是导电的，可以是：固体、液体），是一种有极性的电容器。

分类：铝电解电容、钽电解电容、铌电解电容。

![铝电解电容构造示例]({{IMG:铝电解电容构造示例.png}})

![电解电容图示2]({{IMG:电解电容图示2.png}})

## 正负极区分方法：

**插件电容**：
+ 接线长的那一端为正极，短的那一端为负极。
+ 颜色浅色那端为负极。

**贴片电容**：
+ 黑色标记一侧为负极。

## 特点

1. 容值通常都很大（0.5pF ~ 10000uF）。
2. 额定电压 2.5V ~ 500V。
3. 储能密度高（同样体积下储存的能量更多）。
4. 电解质会随时间蒸发掉，影响其寿命。
5. 有极性，不能在交流电中使用。

**应用场景**；对低频直流进行滤波、闪光灯、汽车安全气囊、电机启动。

# 07-空气电容

以空气作为电介质的电容器，通常是以可调电容器的形式出现。

![空气电容长什么样]({{IMG:空气电容长什么样.png}})

特点：
1. 容值较小（100pF ~ 1nF之间）。
2. 空气的介电常数不是很高，一般不会出现在高压电路中。
3. 良好的抗磁性。

**应用**：高频电路（无线电调谐、广播设备），医疗设备（核磁）。

# 08-超级电容

**超级电容**：一种容量极大的电容器，储能密度比普通电容器高很多，具有极快的充放电速度。

**分类**：静电双层电容器（物理机制储能）、电化学赝电容器（化学机制储能）、混合电容器（上述二者混合）。

EDLC(Electrostatic Fouble Layer Capacity)（静电双层电容器）。

# 01-什么是半导体

**一种介于导体和绝缘体之间的材料，有时导电，有时不导电，其导电性取决于外部条件（如：温度、光照、电压等）**

没有半导体，就没有现代科技。

---
# 02-本征半导体

1. 硅晶体在高温下，能从绝缘体变为导体，是其材料的天然物理特性，是不需要参杂任何的其他成分。我们将这类材料称为本征半导体。
2. 本征激发：指在本征半导体中，由于外部的热能、光能、电场等激励下，使原本处于价带的电子被激发到导带，从而在材料内部形成：电子 + 空穴对的现象。

**注意**：$\color{red}{本征半导体是电中性的}$

---
# 03-N型半导体

**N型半导体**：像硅晶体中参杂适当的磷原子磷原子最外层有5个电子，它会和周围四个硅原子组成4个共价键，这样每个磷原子都可以提供一个自由电子。

1. **纯硅**已经是半导体了，为什么还要参杂磷呢？
**能让半导体导电性能更好，让半导体导电性更容易控制。**

2. 为什么叫N型半导体？
由于磷元素的加入，**带来了更多自由电子，使半导体负电荷载流子的数量大幅增加**，因此这种半导体被称为N型($Negative$)半导体。

3. N型半导体，几乎都是搭配P型半导体一起来使用，形成PN结。

**载流子**：在到点过程中能够携带电荷并产生电流的粒子，在金属导体中，载流子是自由电子，在某些盐溶液中，载流子可能是正离子或负离子。

**N型半导体也是电中性的**

---
# 04-P型半导体

向硅晶体中参杂硼原子，硼原子最外层只有三个电子，硼原子会努力和周围的硅原子形成共价键。并且会缺一个电子，形成“空穴”。

+ 对于N型半导体，更多的载流子是电子（电子是多子，空穴是少子）
+ 对于P型半导体，更多的载流子是空穴（电子是少子，空穴是多子）

对于P型半导体来说，更多的载流子是空穴，空穴可以认为是带正电的($Positive$)。

**P型半导体也是电中性的**。

# 06-二极管的分类

**概述**：由半导体制成的元器件，只允许在单方向流动，是电路中的“单向阀门”。

+ 整流二极管：整流、防反接、防倒灌。
+ 稳压二极管：反接在电路中，一般与电阻搭配使用，完成降压稳定。
+ 发光二极管：红外接收、遥控。
+ 光电二极管：红外接收，遥控。
+ 瞬态抑制二极管：反接在电路中，用于吸收尖峰脉冲、防静电。

---
# 整流二极管

+ 正向压降($V_{F}$)：当二极管处于正向偏置时，二极管导通所需的电压。
+ 反向漏电流($I_{R}$)：二极管在反向偏置时流过的微小电流（通常为纳安，微安级，高温下会增大）。
+ 最大重复反向电压($V_{RRM}$)：二极管在反偏下，能重复承受的最大电压，超过此值可能导致损坏。
+ 最大平均整流电流($I_{AV}$)：二极管能够持续承受的最大电流，超过此值，可能因热而损坏。
+ 最大峰值正向浪涌电流($I_{FS}$)：二极管在短时间内，能承受的瞬时最大电流（如开机浪涌）。

# 07-稳压二极管/齐纳二极管

## 概念

**概述**：稳压二极管利用了二极管反向击穿的特性，它在反向击穿后可以在其两端电压，维持在一个相对稳定的值附近，它为电子设备提供稳定的电压，并防止过压损坏。

![稳压二极管图]({{IMG:稳压二极管图.png}})

1. 反向击穿电压会低一些，更容易利用到其反向击穿后的特性。
2. 当反向击穿后，不管通过它的电流是多少，它两端的电压，都会稳定在一个固定值附近。

## 相关参数

+ 稳压值($V_{Z}$)：稳压二极管在反向击穿区时，其两端能够维持的稳定电压，受电流和温度影响。
+ 耗散功率($P_{d}$)：稳压二极管能够承受的最大功率，实际应用中需留有余量（通常>=30％）。
+ 最大工作电流($I_{Zmax}$)：稳压二极管允许通过的最大电流。
+ 最小稳压电流($I_{Zmin}$)：稳压二极管达到稳压效果，所需的最小反向电流。

# 发光二极管($Lighting Emitting Diode$)
## 概念

**概述**：一种能将电能转化为光能的半导体器件，其核心原理是**电致发光效应**。
+ 电致发光效应 ![电致发光效应]({{IMG:电致发光效应.png}})
+ 光生伏特效应：![光生伏特效应]({{IMG:光生伏特效应.png}})

应用：照明（白光）、指示灯（彩色）、验钞（紫外光）、遥控（红外光）。

![发光二极管符号]({{IMG:发光二极管符号.png}})

## 相关参数

+ 正向电压($V_{f}$)：LED导通时其两端的压降，与材料和颜色无关。
+ 额外正向电流($I_{f}$)：LED在正常工作状态下，能够持续通过的最大电流。
+ 功率($P_{d}$)：功率直接关系到发热量。功率较大的LED需要更好的散热设计。
+ 发光强度：单位是“坎德拉（cd）”，光强越大，亮度越高。
+ 发光角度：窄角度：15° ~ 30°，光线集中，中心光强高。宽角度：120° ~ 180°，光线分散，覆盖范围广。
+ 工作温度：LED能够稳定运行的温度范围。

在电子连接器领域，**端子**和**针座**是一对形影不离的搭档，它们一“软”一“硬”，共同完成“连接导线与电路板”的任务。

在立创商城里面，针座又叫作**线对板针座**。

需要的工具除了端子和针座外，核心工具还有**压线钳**。
# 端子：

**端子**是**负责导电的金属零件**，用黄铜、磷青铜等制成，表面常镀锡或镀金。
+ 功能：夹紧导线、与对方金属针接触，实现电流导通。
+ 用法：用压线钳把端子和导线压紧，然后推入塑料胶壳（母壳），变成可插拔的母端线束。

# 针座：

**针座**是 **带插针的绝缘塑料基座**，通常焊接在电路板（PCB）上，作为公端固定件。
+ 功能：提供固定位置、通过插针与端子的母孔对接，实现板对线的电气连接。
+ 用法：直接焊在电路板指定位置上，等待带端子的胶壳直接扣上。

# 尺寸：
他们的核心区别就是**间距**（单位：毫米）。
## 常用的尺寸型号

| 编号  | 核心系列 (间距)       | 参考单价 (外壳/针座) | 主要应用场景                    |
| :-- | :-------------- | :----------- | :------------------------ |
| 1   | **PH (2.0mm)**  | ¥0.1 - ¥0.5  | **小型锂电池**, 舵机, 3D打印机, 开发板 |
| 2   | **XH (2.5mm)**  | ¥0.1 - ¥0.5  | **更大容量电池**, 航模平衡充, 电源引入   |
| 3   | **GH (1.25mm)** | ¥0.5 - ¥5+   | OLED/LCD屏幕, 微型传感器, 紧凑的模块  |
| 4   | **SH (1.0mm)**  | ¥0.1 - ¥0.5  | 极微型设备: 微型传感器, 可穿戴设备       |
| 5   | **VH (3.96mm)** | ¥0.1 - ¥0.5  | 电源模块, LED照明, 工业设备         |
## 测量：

用尺子或卡尺量一下PCB板上针座相邻两个针脚中心的距离。
*   距离是1.25mm，选 **GH** 系列。
*   距离是2.0mm，选 **PH** 系列。
*   距离是2.5mm，选 **XH** 系列。

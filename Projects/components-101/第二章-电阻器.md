# 01-概述

**概述**：在电路中产生电阻的元器件，主要作用是阻碍电流的流动，是最常见的元器件之一。

**分类**：固定电阻、可调电阻、特种电阻。

**关键参数**：
+ 阻值：阻值越大，对电流的阻碍能力就越强，反之就越弱。
+ 功率：指电阻长时间连续工作能够承受的功率。
+ 精度：一般的精度只有1％和5%，精密的有0.1%，有的甚至可达0.01%。（最后生产出来的阻值精度误差）

**注意点：电阻的外观大小，和阻值没有必然联系，外观大小通常和功率有关。**

---
# 02-线绕电阻

## 工艺

把电阻丝（镍铬、锰铜等）绕在一个绝缘骨架（陶瓷等）上制成，电阻丝的：材料、长短、粗细，决定着阻值的大小，最后在外层图上绝缘材料（环氧树脂，漆皮等）进行密封。
![绕线电阻图示]({{IMG:绕线电阻图示.png}})

## 特点

1. 精度可以做的较高，最高可达$\pm0.01％$
2. 能承受较大功率，甚至可达几kW左右。
3. **成本略高**
4. TCR较低：大致是 20ppm/℃ ~ 200ppm/℃ 
+ *TCR(Temperature Coefficient of Resistance为温度系数，表示电阻值随温度变化的程度，单位是PPM。*
+ *PPM(Part Per Million)，指每摄氏度的百万分率，每增加或降低一度，阻值变化百万分之多少*
5. 特别注意：由于存在寄生电容和寄生电感，不适用高频场景使用.
+ 高频场景：wifi、蓝牙、卫星通信、雷达系统等。
+ 实际制造电阻时，可通过特殊绕线的方式，尽量去消除寄生电容、寄生电感。

# 03-碳膜电阻

## 工艺

把高温下分解出来的“结晶碳”，蒸馏沉积在陶瓷棒上，随后在碳膜上刻出螺旋槽，通过螺旋槽的宽度和长度，来控制阻值，最后在外层涂上环氧树脂来密封。
![碳膜电阻图示]({{IMG:碳膜电阻图示.png}})

## 特点

1. 精度略低：常用的为$\pm5$％ 左右，最高精度也就$\pm1％$左右。
2. 功率范围：$\frac{1}{8}W到5W$之间。
3. **成本较低**
4. TCR一般：大致是200ppm℃ ~ 500ppm℃
5. **负温度系数**：随着温度升高，阻值会变小。

适用于：对精度要求不高，且要控制成本的设备中，例如：老式用电器，电动玩具。

---
# 04-金属膜电阻

## 工艺

在高温真空的环境下，将**金属膜**（如镍铬合金）镀在陶瓷棒上，随后通过蚀刻工艺，在金属膜上可出螺旋槽，同样是通过螺旋槽的宽度和长度来控制阻值。
![金属膜电阻图示]({{IMG:金属膜电阻图示.png}})

## 特点

1. 性能更加稳定
2. **精度较高**：常用的一般为$\pm1％$左右，最高精度可达$\pm0.01％$左右
3. 功率范围：50mW ~ 20W之间。
4. **成本较低**
5. TCR较低：大致是 50ppm/℃ ~ 100ppm/℃之间。

适用于对精度要求略高的设备，例如：万用表的主板等。

---
# 05-贴片电阻

## 工艺

在绝缘基板上铺上电阻材料，随后刻出不同的纹路来控制阻值。
![贴片电阻示例]({{IMG:贴片电阻示例.png}})

## 厚膜电阻和薄膜电阻

### 厚膜电阻

+ 工艺：把金属氧化物（氧化钌）和玻璃混合的浆料，涂在绝缘基板上，形成的电阻层。
+ 膜厚度：通常在100微米左右
+ 精度：常见$\pm1％$ ~ $\pm5％$,最高为 $\pm0.1％$。
+ TCR：大致是50ppm/℃ ~200 ppm/℃。
+ 抗氧化能力相对好一些。
+ 价格便宜
+ 适用于：一般消费电子，汽车电子，家电等领域。

### 薄膜电阻

+ 工艺：采用真空沉积的精细工艺，把合金（镍铬合金）涂在绝缘基板上，形成的电阻层。
+ 精度：常见$\pm1％$ ~ $\pm2％$,最高为 $\pm0.01％$。
+ 功率范围：10mW ~ 3W之间。
+ TCR： 大致是 5ppm/℃ ~ 50ppm/℃。
+ 抗氧化能力不是很好。
+ 价格稍贵
+ 适用于：精密设备（高端设备，高端测量设备等）

**厚膜电阻覆盖了90％左右的消费类电子产品。**

## 封装尺寸

如：0402即长为0.04英寸，宽为0.02英寸。0805即长为0.08英寸，宽为0.05英寸。

# 06-金属箔电阻

## 工艺

把合金（镍铬合金等）与添加剂混合，做成厚度控制在几微米范围内的膜，涂在绝缘体（陶瓷）上，随后刻蚀成不同的纹路来控制阻值。
![金属箔电阻示例]({{IMG:金属箔电阻示例.png}})

## 特点

1. 性能极其稳定。
2. 精度极高：常用的为 $\pm0.01％$，最高精度可达 $\pm0.001％$。
3. 功率范围：1/16W ~ 15W之间。
4. 成本很高：一个大概57块。
5. TCR极低：常见的是 1ppm/℃，特殊制造的可达0.05ppm/℃。
6. 低噪声、耐静电、地感电容。

适用于：对可靠性和精度要求极高的场景，例如：航空航天领域、军工领域，医疗领域等。

# 07-可调电阻

# 概述

概述：相比于固定电阻，多了一个调节结构，常见的封装类型有旋转式，滑动式等。

结构：有电阻材料，划片，引脚组成，划片与电阻轨道不同位置接触，可以改变电阻值。

# 08-特种电阻-保险丝

## 概念

+ 概述：属于限流保护类型的元器件，可以看成是一种特殊的电阻。
+ 原理：当电流高于某一阈值时，会产生熔断，从而保护电路。

关注参数：
+ 额定电流：正常工作时，能够承受而不熔断的最大电流。 
+ 融化特性：分为：快速保险丝、延迟保险丝（可短时间承受一点过的浪涌电流。）
+ 分断能力：发声短路或者严重过载时，能够安全断开电流的最大能力；如果实际超出分段电流时，保险丝可能会出现：破碎、爆炸、喷溅、引起周围元器件的燃烧或破坏。
+ 耐压值：熔断之后，断开的熔丝之间不会产生电弧的电压值，实际高于该值时，可能无法有效地切断，，有严重的安全隐患。
![保险丝图示]({{IMG:保险丝图示.png}})

# 09-特殊电阻-光敏电阻（光导管）

## 概念

概述：对光敏感的电阻，其阻值会随光照强度而改变，通常规律：黑暗中组织高，光照下阻值小。

材料：硫化镉、硒化镉（注意：镉化物有毒）。

![光敏电阻图示]({{IMG:光敏电阻图示.png}})

## 特点

关键参数：
+ 亮电阻：指光照强度在10Lux下，所测得的阻值。
+ 暗电阻：指光线强度从10Lux变到0Lux后10秒钟时的阻值。
+ γ值：光敏电阻阻值与光线变化之间的系数，γ值越大

电路符号：
![光敏电阻电路符号]({{IMG:光敏电阻电路符号.png}})

+ 根据响应的波长范围，可分为：可见光光敏电阻、红外光光敏电阻、紫外光光敏电阻.
+ 光敏电阻不适合做线性操作，常见应用：光感灯。

# 10-特殊电阻-压敏电阻

## 概念:

概述：一种限压型保护器件，其两端电压超过一定阈值时，阻值会急剧下降到一个最低值，电流会从其自身通过，从而实现对后方电流的保护。

材料：氧化锌+陶瓷

![特殊电阻-压敏电阻图示]({{IMG:特殊电阻-压敏电阻图示.png}})
## 特点

+ **压敏电压**：随着电压的升高，压敏电阻的阻值出现变小趋势的拐点电压。
~~~
为了标准化需要，国际电工委员会，规定了两个测量压敏电阻的参考值，分别是1mA和0.1mA，将在这一电流下所得电压，规定为压敏电压。
~~~
+ **最大连续工作电压**：指压敏电阻在长期工作下，不发生性能劣化或损坏的最大电压。
+ **最大限制电压**：此电压下，压敏电阻的阻值低到极限值，超过该电压会导致其损坏。

![压敏电阻符号]({{IMG:压敏电阻符号.png}})

# 11-阻值识别

## 1-直标

![电阻直标表示方法]({{IMG:电阻直标表示方法.png}})

## 2-三位数字代码

一般适用于精度为$\pm5％$的电阻，前两位是有效数字，第三位数字表示在有效位后面加0的个数，字母R表示小数点。

![电阻三位数字代码表示]({{IMG:电阻三位数字代码表示.png}})

## 3-四位数字代码

一般适用于精度为$\pm1％$的电阻，它的前三位是有效数字，第四位表示在有效数字后面所加0的个数，**字母R表示小数点**。

![电阻思维数字代码表示]({{IMG:电阻思维数字代码表示.png}})
## 4-精密标注

一般用于精度为$\pm0.1％$的电阻，它是由两位数字加一位字母表示，前两位数字表示的阻值，要通过**查表**获得，最后一位字母表示倍数关系，也需要通过查表获得。

![电阻精密表示以及查表]({{IMG:电阻精密表示以及查表.png}})

## 5-色环（important）

插件类型的电阻喜欢用色环标记。

![电阻色环标记表示]({{IMG:电阻色环标记表示.png}})

# 概述实验板的组成部分

该单片机的型号是**IAP15F2K61S2**，是STC公司生产的**51系列1T型单片机**，在1T模式下**比传统8051快8-12倍**,内部有R/C振荡电路，可以不借助外部晶振，通过STC的ISP下载器调节内部时钟的频率。K61表示内部Flash有61kb，S2表示有2个串行口。

板子上主要的模块有：

+ 8位数码管
+ 8个LED灯
+ 4×4矩阵键盘(也可用作独立按键)
+ Ds1302时钟模块
+ Ds18b20温度模块
+ Uln2003驱动芯片(驱动继电器，蜂鸣器等)
+ Pcf8591 ad转换芯片
+ At24c02 EEPROM存储器芯片
+ 超声波发送接收模块

# 程序开头的写法

## 使用reg52.h开头的程序

~~~C
#include "reg52.h"

sfr P4 = 0xc0;// reg52.h 头文件中没有定义P4寄存器，故要自己定义
sbit P3_6 = P4^2;// 位定义用 P3_6 在程序中替换 P4^2 的功能
sbit P3_7 = P4^4;// 同上

~~~

## 使用STC15F2K60S2.H开头的程序

~~~C
#include "STC15F2K60S2.H"

sbit P3_6 = P4^2;// 位定义用 P3_6 在程序中替换 P4^2 的功能
sbit P3_7 = P4^4;// 同上
~~~

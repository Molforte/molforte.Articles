# 延迟函数

我觉得那个up主的视频，延时函数很粗糙，并不能满足需求，且不同的板子出现不同步的问题（比如24年的这个板子就不能用他生草的延迟120000。所以务必用stcisp做出来的延迟函数来延时。

## 延迟1s

~~~C
void Delay1000ms(void)  //@11.0592MHz
{
    unsigned char data i, j, k;

    _nop_();
    _nop_();

    i = 43;
    j = 6;
    k = 203;
    do
    {
        do
        {
            while (--k);
        } while (--j);
    } while (--i);
}
~~~

void Delay1ms(void) //@11.0592MHz

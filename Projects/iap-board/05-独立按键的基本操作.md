首先将J5处的跳帽接到2~3引脚，使按键S4~S7四个按键的另外一端接地，从而称为4个独立键盘。

扫描按键的过程中，发现有按键触发信号后，先做去抖动处理，认为按下按键时，再做相应处理。（和51单片机一样）。

~~~C
#include "STC15F2K60S2.H"
#include <intrins.h>
  
sbit S7 = P3^0;
sbit S6 = P3^1;
sbit S5 = P3^2;
sbit S4 = P3^3;
  
sbit L1 = P0^0;
sbit L2 = P0^1;
sbit L3 = P0^2;
sbit L4 = P0^3;
sbit L5 = P0^4;
sbit L6 = P0^5;
sbit L7 = P0^6;
sbit L8 = P0^7;
  
void SelectHC573(unsigned char channel){
    switch(channel){
        case 0:
            P2 = (P2 & 0x1f) | 0x80;
            break;
        case 1:
            P2 = (P2 & 0x1f) | 0xa0;
            break;
        case 2:
            P2 = (P2 & 0x1f) | 0xc0;
            break;
        case 3:
            P2 = (P2 & 0x1f) | 0xe0;
            break;
    }
}
  
void Delay1ms(void) //@11.0592MHz
{
    unsigned char data i, j;
  
    _nop_();
    _nop_();
    _nop_();
    i = 11;
    j = 190;
    do
    {
        while (--j);
    } while (--i);
}
  
void ScanKeys_Alone(){
    if(S7 == 0){
        Delay1ms();
        if(S7==0){
            L1 = 0;
            while(S7==0);
            L1 = 1;
        }
    }
    if(S6 == 0){
        Delay1ms();
        if(S6==0){
            L2 = 0;
            while(S6==0);
            L2 = 1;
        }
    }
    if(S5 == 0){
        Delay1ms();
        if(S5==0){
            L3 = 0;
            while(S5==0);
            L3 = 1;
        }
    }
    if(S4 == 0){
        Delay1ms();
        if(S4==0){
            L4 = 0;
            while(S4==0);
            L4 = 1;
        }
    }
}
  
void main(){
    P0 = 0xff;
    SelectHC573(3);
    while(1){
        ScanKeys_Alone();
    }
}
~~~

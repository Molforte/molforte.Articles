# L2 目标检测与网络结构 · 组员共享版
> 用途：答辩谈到"模型/网络"时用。建议先读 L1 组员版再读本文。核心问题："YOLO 是什么思路？你的网络长什么样、为什么这么设计？"

## 1. 两个基础概念（答辩必答）
**分类 vs 检测**：分类=整张图给 1 个标签（"这是什么"）；检测=输出**若干个**目标，每个含 类别 + 框位置 + 置信度（"有几个、在哪、是谁"）。
**YOLO 的网格思路**：目标个数不固定，网络输出必须形状固定。于是把图按"格子"看待：**每个格子只对"中心点落在自己格内的目标"负责**，预测内容固定为"框相对格子的偏移 + 宽高缩放 + 类别概率 + 目标度"。再配合**锚框（anchor）**：预先给每种尺度 3 个典型框形，网络只预测"离哪个框形差多少"，比从零回归宽高更好收敛。

## 2. 网络解剖（答辩现场能画出这条链）
```
输入 352×352×3
→ conv0: 3×3 卷积, 步长2, 3→24 通道        → 176×176×24
→ MaxPool 3×3 步长2                          →  88×88×24
→ stage2: 4 个 ShuffleV2Block (首块步长2)    →  44×44×48
→ stage3: 8 个 Block (首块步长2)             →  22×22×96
→ stage4: 4 个 Block (首块步长2)             →  11×11×192
→ LightFPN 融合（见下）
→ 检测头 → 输出两张预测图: 22×22 与 11×11
```
**下采样链（背）**：352 → 176 → 88 → 44 → 22 → 11，共 6 次减半（conv0、池化、stage2/3/4 首块各一次）。分辨率越低，计算量越小（面积降为 1/4），所以网络敢在后期把通道加厚到 48/96/192。
**为什么叫"特征图"而不是"缩小的图"**（⚠️ 团队口径，最容易说错）：22×22/11×11 不是原图的缩略图，而是 79 层卷积算出来的**抽象特征图**——每个通道是"某种滤波器响应图"（有的通道响应火苗纹理、有的响应边缘），人眼看不懂，但机器靠它判断"哪里有目标"。卷积的作用正是把"像素"逐层变成"语义"。

**ShuffleV2Block（轻量的秘诀）**：先"通道洗牌"拆成两半，一半走主干（1×1→3×3 深度卷积→1×1），另一半直接拼接。全程不增加通道 → 省计算。
**FPN（特征金字塔，⚠️ 拼接对象要说对）**：深层（11×11，语义强但图小）先用 1×1 降到 72 通道，再**上采样放大 2 倍到 22×22**，与 stage3 的 22×22×96 **拼接**成 288 通道，再用 1×1 压回 72。→ 让"大图"也带上高层语义，小目标检测才可能。
**检测头**：每尺度有 cls/reg 两条并行支路，各由 5×5 深度卷积(DW) + 1×1 组成；最终输出每格 **21 通道** = 3 锚框×(4 回归+1 目标度) + 6 类别（3 锚框共享类别）。

## 3. 答辩表述（30–60 秒版，按自己话讲）
> "我选用 YOLO-FastestV2：灾后救援要上板实时，模型必须轻——它只有 0.23M 参数、INT8 后约 250KB。网络分三部分：轻量骨干（ShuffleV2Block 堆叠）把 352 的图逐级下采样提炼语义，到 44/22/11 三个分辨率、通道加到 48/96/192；LightFPN 把深层的语义上采样后和浅层融合，兼顾小目标；最后双尺度检测头输出 22×22 与 11×11 两张预测图，每格预测 3 个锚框的目标。训练数据是灾后场景的 6 类目标（person/fire/smoke/small_veh/large_veh/2whl），AP 约 66%。"

## 4. 追问防御（每题先给一句，再展开）
| 问                 | 一句话答法                                          |
| ----------------- | ---------------------------------------------- |
| 特征图是什么？           | 卷积输出的抽象图，每个通道=一种滤波器响应，编码"哪里有火的纹理/边缘"           |
| 为什么输出两张而不是一张？     | 多尺度：22×22 网格(每格=原图16px)抓中小目标，11×11(每格32px)抓大目标 |
| 为什么小目标弱？          | 最细的网格也只有 22×22（16 像素一格），更小目标信号被下采样稀释           |
| 为什么 0.23M 参数这么小？  | 深度可分离卷积 + 通道洗牌把参数/计算压到极致，为板载部署服务               |
| 1×1 / 5×5 DW 是什么？ | 1×1=跨通道混合不跨空间；DW=每通道独立卷积，感受野大但参数只有普通卷积的 1/通道数  |

## 5. 速查数字
- 下采样链：352→176→88→44→22→11（6 次减半）
- 骨干三段输出：44×44×48 / 22×22×96 / 11×11×192
- FPN 拼接：stage4 上采样(→22²) + stage3(96ch) → 288 → 1×1 → 72
- 输出：两张（22²、11²），每格 21 通道（3 anchor × 5 + 6 cls）
- 网络：79 conv（conv0–72 + 6 输出层）；0.23M 参数；6 类；AP≈66%

## 6. 团队口径提醒（防说错）
- ❌ "网络把图切成两张小图/缩略图" → ✅ "卷积逐层下采样，最终产生两张抽象特征图用于预测"
- ❌ "骨干输出是 352×352×24" → ✅ 352×352×3 是**输入**；24 通道出现在 176×176 的第一层卷积后
- ❌ "FPN 把两张输出图拼起来" → ✅ FPN 拼接 stage3 与"上采样后的 stage4"，发生在出预测图**之前**

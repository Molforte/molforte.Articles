## 1. 三分钟看懂这个项目

**题目**：产教融合类 · 赛题 6「典型 FPGA 设计与验证」→ 我们做《基于 FPGA 的灾后救援目标检测专用芯片设计与验证》。

**一句话**：把针对火灾/烟雾等 **6 类目标**的目标检测网络 YOLO-FastestV2 跑上 Zynq-7020（ARM+FPGA 异构 SoC），并用 PL 可重构硬件加速最耗时的卷积，做成"专用芯片原型 + 真机验证"。

**三人分工**（答辩口径要一致）：

| 角色   | 负责                     | 核心产出                    |
| ---- | ---------------------- | ----------------------- |
| 队友 A | PyTorch 模型训练 + INT8 量化 | 权重头文件 / 量化参数            |
| 队友 B | ARM 端 C 推理软件（金标）       | 逐层推理 + 解码 NMS 代码        |
| 组长   | FPGA PL 硬件加速 + 系统集成    | HLS 内核 → 位流 → 5–6× 加速数据 |

**最终成果（背数字）**：
- 单张 352×352 推理：纯 PS（ARM 软件）约 **15–20 s** → PS+PL 协同 **3.3 s ≈ 5–6× 加速**
- 检测结果与纯软件**逐位一致**（硬件没算错）；串口输出 5 个框（1 smoke + 4 fire）
- 硬件指标：PL 上 INT8 卷积内核，BRAM 131/280、DSP 53/220、100MHz 时序收敛

## 2. 基础信息：系统数据流五站

```
[图片] → ①PC预处理 → ②逐层卷积 → ③解码 → ④NMS去重 → ⑤串口打印
```

| 站      | 干什么                 | 谁负责                           | 一句话原理                    |
| ------ | ------------------- | ----------------------------- | ------------------------ |
| ① 预处理  | 任意图→352×352、转成 int8 | PC 工具                         | 图缩到固定大小（会失真，是部分网图检不出的原因） |
| ② 逐层卷积 | 79 层乘加变换，提炼"哪里有火"   | **大部分 PS + 14 层 1×1 卷积外包 PL** | 重复的乘加 = AI 推理的全部体力活      |
| ③ 解码   | 特征 → "框+类别+分数"      | PS（main.c）                    | 把 21 通道/格翻译成坐标与概率        |
| ④ NMS  | 去掉同类别重叠的多余框         | PS                            | 只留每处目标最可信的一个框            |
| ⑤ 输出   | 打印类别/数量/框/置信度       | UART 硬件                       | 串口 `D 5 smoke … OK`      |

**两个必须会答的基础概念**：
- **MAC** = 一次"乘+加"。全网络约 **1.03 亿次 MAC**。CPU 一条条指令算→慢；FPGA 把乘加"铺"成并行电路→快。
- **为什么是"专用芯片"**：赛题要求"设计专用芯片并用 FPGA 原型验证"。我们的专用加速器 = 一个 INT8 卷积内核，在 PL 上可重构实现；5–6× 加速 + 结果逐位一致 = 证明这个设计正确。

## 4. 项目怎么来（时间线 · 决策 · 踩坑）

### 4.1 关键决策 & 理由（答辩被问"为什么这样设计"用）
1. **为什么选 Zynq-7020**：ARM+FPGA 异构，正好做"软件灵活性 + 硬件加速"对比实验，且是"真 SoC 芯片"形态，契合赛题"专用芯片"。
2. **为什么选 YOLO-FastestV2**：只有 **0.23M 参数**、INT8 后约 250KB，嵌入式板载放得下、算得动。
3. **为什么 INT8**：存储/带宽降到 1/4，精度损失可控（L4 文档详述）。
4. **为什么 14 层走 PL**：这 14 个是 K=1 的 1×1 卷积，尺寸在硬件缓冲上限内；8 个 5×5 深度卷积超内核 MAX_K=3 上限，自动回退 CPU（L7 文档详述）。

### 4.2 踩过的坑（讲出来是加分项——体现工程过程）
1. **早期位流是"单层固定权重"简化版**，不能换权重跑 79 层 → 重综合带权重寄存器的可换权重内核。
2. **浮点 scale 进硬件太贵** → 改成 Q16.16 定点 scale。
3. **早期 stream+DMA 方案** → 改为内核 m_axi 直读 DDR、去掉 DMA，简化数据通路。
4. **量化/BN/ReLU 位置曾出错导致检不出目标** → 用 numpy 金标逐层对拍定位修复（L5 文档详述）。

## 6. 速查表（考前背这张就够）
- 平台：Zynq-7020 XC7Z020-2CLG400I · 正点原子领航者 V2 · Vivado/Vitis 2025.2.1
- 输入：352×352×3 · 输出：22×22 + 11×11 两张特征图（stride 16/32）
- 网络：79 conv（conv0–72 + 6 输出层）· 0.23M 参数 · INT8≈250KB · 6 类（person/fire/smoke/small_veh/large_veh/2whl）· AP 66.01%@epoch80
- 计算量：约 1.03 亿 MAC（backbone ~71%、fpn/head ~28%）
- 分工：PS 全管线 + 解码 NMS；PL 加速 14 个 K=1 卷积；8 个 K=5 自动回退
- 结果：15–20 s → **3.3 s（5–6×）**；PL calls=22 errs=0；检测框逐位一致
- 硬件资源：BRAM 131/280 · DSP 53/220 · 100MHz 时序收敛

# FPGA 灾后救援目标检测专用芯片

在 Xilinx **Zynq-7020**（正点原子领航者 V2）上，把针对火灾、烟雾等 **6 类目标**的
**YOLO-FastestV2** 检测网络做成"PS 软件 + PL 硬件加速"的系统：ARM 负责整条推理管线，
PL 上实现可换权重的 **INT8 卷积加速内核**，承担 14 层 1×1 卷积。

**结果**：单帧推理从纯软件 15–20 s 降到 **3.3 s（≈5–6×）**，检测结果与纯软件**逐位一致**。

## 核心数字

| 项 | 值 |
| --- | --- |
| 平台 | Zynq-7020 XC7Z020-2CLG400I，100 MHz |
| 输入 / 输出 | 352×352×3 → 22×22 + 11×11 两张预测图（stride 16/32） |
| 网络 | 79 层卷积（conv0–72 + 6 输出层），0.23 M 参数，INT8≈250 KB |
| 计算量 | ≈1.03 亿 MAC（backbone ≈71%） |
| 类别 / 精度 | 6 类（person/fire/smoke/small_veh/large_veh/2whl），AP 66.01% |
| 加速 | 15–20 s → 3.3 s，≈5–6×；`PL calls=22 errs=0`（14 层真上 PL + 8 层回退） |
| 资源 | LUT 5.4 K/53 K、BRAM 131/280、DSP 53/220，WNS +0.297 ns |
| 验证 | float↔PyTorch ≤1.4e-5；INT8↔float 余弦 0.83–0.99；C↔numpy 逐字节；板上↔PC 逐字符 |

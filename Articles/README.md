# Articles

独立文章，一篇一个 `.md`。建议文件名 `YYYY-MM-DD-english-slug.md`（slug 决定 URL：`/post/<slug>`）。

```yaml
---
title: 标题
date: 2026-09-10
tags: [随笔]
summary: 可选，不写就取正文第一段
---
```

规则：

- **必须有 `date`**，否则不会出现在首页与归档的「文章」列表里；
- 正文里的站内链接：`[文字](/notes/<册>/<笔记>)`；图片用相对路径或 `{{IMG:文件名}}` 占位符；
- 公式 `$…$` / `$$…$$` 会由站点的 KaTeX 渲染；代码块用围栏并标语言；
- 加 `draft: true` 可以临时不发布（但**文件仍在公开仓库里**，敏感内容别放进来）。

# GPIO：单片机的“感知触角”与“操控之手”

\#GPIO

 敏锐地感知外部环境的各种状态，同时精准地对外部设备下达“指令”，实现两者之间的数据做交互。

## 输出模式

**推挽输出**：强大的双向驱动器，既能输出高电平驱动负载，又能输出低电平。

~~~
      VDD
       │
       ├───[PMOS]
       │
IO引脚──┤
       │
       ├───[NMOS]
       │
      GND
~~~

---
**开漏输出**：单向开关，仅能输出低电平或高阻态。

~~~
      VDD
       │
       │
       │
IO引脚──┤
       │
       ├───[NMOS]
       │
      GND
~~~

## 输入模式

**浮空输入**：完全依赖外部信号电平，无上拉/下拉电阻，高抗阻状态。可以精确感知外部信号的微小变化，因此可以精准检测外部的脉冲信号等。

~~~
      │
      │
IO引脚─┤
      │
      │
~~~
---

**上拉输入**：在没有信号输入时，默认保持高电平状态。一旦有外部低电平到来，能迅速检测到。常用于**按键检测（按键接地）**、开漏总线信号接收（如I2C）、数字传感器接口。

~~~
      VDD
       │
       └─[R=20-50kΩ]
           │
IO引脚──────┤
           │
          GND
~~~
---

**下拉输入**：与上拉输入相反，默认低电平状态。（原理与上拉输入类似）

~~~
          VDD
           │
           │
IO引脚──────┤
           │
           └─[R=20-50kΩ]
               │
              GND
~~~

# PWM：精准控制的“隐形魔术师”

\#PWM

**PWM：脉冲宽度调制**：是一种通过调节脉冲时间占比来控制等小模拟量的数字信号技术。

可用以下公式表达：
$$
V_{avg} = D \times V_{max} \ (0 \le D \le 1)
$$

**两个关键因素：频率和占空比**。频率决定了脉冲信号的变化速度，类似于音乐节奏的快慢；而占空比则是 一个脉冲周期内 高电平持续时间与整个周期时间的比值，它就像音符的长短，直接影响信号的平均电平。

应用：电机调速，Led调光，DAC模拟，音频合成。

*这个正是Led呼吸灯的典型应用，通过动态调节占空比来实现亮度渐变。*（兴趣方向，了解即可）

1.线性渐变

$$
D(t)=D{min}+\frac{D{max}-D{min}}T·t
$$

2.非线性渐变

$$
D(t)=\frac{D{max}-D{min}}2(1-cos(\frac{Πt}T))+D{min}
$$

# ADC：单片机感知模拟世界的“超级翻译官”

\#ADC

**将连续模拟信号转化为离散数学值的核心模块**。

# IRQ：单片机高效响应外部世界的“紧急信使”

\#IRQ

在单片机运行过程中，需要时刻面对外部环境的各种突发情况和变化。

然而，单片机的资源和处理有限的，如果让单片机持续不断地查询外部设备的状态，会极大地浪费资源，降低系统效率。

**IRQ（Interrupt Request）中断请求**的运作方式完美解决了“持续轮询浪费资源”的问题，核心通过**硬件触发+事件驱动**实现高效响应。

***感觉像是一个哨兵，随时响应中断，并及时保存现场***。

~~~
🛡️ 瞭望哨（GPIO/外设） → 📡 通信兵（中断控制器） → 🧠 指挥中枢（CPU）
~~~

### 1.常态警戒模式：

~~~
[主程序]
↓
CPU 执行常规任务（如数据处理）
↓
哨兵系统处于「休眠警戒」状态（功耗可能低至 μA 级）
~~~

### 2.事件触发阶段

~~~
外部事件（如按键按下） → 瞭望哨立即拉响警报（IRQ信号）
↓
通信兵（NVIC）评估事件等级：
   - 火警（高优先级）：直接打断当前任务
   - 普通警报（低优先级）：排队等待处理
~~~

### 3.应急响应协议

~~~
指挥中枢（CPU）收到警报后：
1️⃣ 瞬间冻结当前工作现场（自动保存 PC/PSR 到栈）
2️⃣ 调取应急预案（跳转到 ISR 中断服务程序）
3️⃣ 应急小组（ISR）快速处置：
   - 确认事件来源（检查中断标志）
   - 执行关键操作（如记录按键时间）
   - 清理现场（清除中断标志）
4️⃣ 恢复原有任务（从栈中还原现场）
~~~

# TIMER：单片机精准运行的顶级时钟大师

\#TIMER

默默地掌控时间的节奏，让单片机精确地执行各种任务，有条不紊地执行。*玩过51单片机定时器的都知道。*

**定时器（Timer）** 是精准控制时序的核心模块，本质是**可编程的硬件计数器**。

# UART：单片机通信的“信息快递员”

\#UART

**UART（Universal Asynchronous Receiver/Transmitter）** 是实现设备间**异步串行通信**的核心外设，其核心特征是通过两根信号线（TX/RX）**实现全双工数据传输**。

像是一个可靠的“信息快递员”，实现了单片机与外部设备之间重要的信息传递的重要任务。

# USB：另一家快递公司

\#USB

*这玩意可太熟了*。**USB(Universual Serial Bus)** 即通用串行总线，广泛用于计算机与电子设备之间的通信接口标准。

# Multicore：单片机的“多核智慧引擎”

\#Multicore

**多核处理器（Multicore）** 是指单个芯片上集成多个独立 CPU 核心，通过**并行计算**和**任务分配**提升系统性能与实时性。

## 多核处理器的典型架构

### 1.同构多核（Homogeneous）

~~~
Core0 ──┬── 共享 L2 Cache ── RAM
Core1 ──┘
~~~

+ **特点**：所有话就核心规格相同。
+ **应用场景**：负载均衡（如并行数据处理）。

### 2.异构多核（Heterogeneous）


~~~
Cortex-M7（高性能核）──┬── 共享内存
Cortex-M4（低功耗核）──┘
~~~

+ **特点**：不同核心分工合作。
+ **应用场景**：M7处理算法，M4管道外设。
